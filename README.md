# AC SHARK Exam Trainer

**Live site:** [https://geaux72degrees-oss.github.io/ac-shark-public-study/](https://geaux72degrees-oss.github.io/ac-shark-public-study/)

Texas Environmental Air Class A (PSI) study site. Works on phone and computer.

- Coach Home: next lesson, today's training, exam readiness (locked until 20 answers)
- Library includes photo-verified Modern Refrigeration 22e locators (page numbers only)
- Learn, Practice, and 125-question timed exam lab
- Open access — no password
- No personal names or license numbers on this site
- Full textbooks stay in Drive or on paper. This site does not host the books.
- Practice questions are original. They are not PSI items.

Exam model on this site: 125 questions, 230 minutes, 70% to pass.
Exams on or after September 1, 2026 use the 2024 UMC, IMC, and IFGC.

Progress key in the browser: `ac-shark-study-v3-public`.
Prior public build from 2026-09-04 remains in git history.
